# コンセプト仕様「あきはと旅するポートフォリオ」

一言: **サイト全体は、相棒（マスコット=あきは）と一緒に過ごす秋の世界。**
判断基準: すべてのギミックは「相棒が生きている」ことに奉仕する。奉仕しないギミックは追加しない・削る。

対象: Google AI 学生コミュニティ Discord特別委員会メンバーとしての自己紹介サイト。
主要訪問者は Discord から来る仲間。温かく・遊び心があり・その上で制作物の中身（化学工学×AI）は真面目に読ませる。

## C1. 常駐相棒（companion）— 貫徹の核

小型の分身（デスクトップ約96px / モバイル約72px）が画面右下に常駐し、旅に同行する。
素材: `aki_ha_body_front.png` + `aki_ha_eye_l/r.png` + `aki_ha_mouth.png`（目は本体の上にレイヤー合成し瞳を動かす）。

### 行動表（状態機械）

| 状態 | 発火条件 | ふるまい |
|---|---|---|
| appear | ヒーロー通過後 | ふわっとフェードイン（冒頭の物語から「住み着いた」文脈） |
| idle | 常時 | 呼吸（scale 1↔1.015、ゆっくり）+ 数秒おきにまばたき |
| watch | pointer:fine | 瞳がカーソル方向をわずかに追う |
| sleep | 20秒無操作 | 目を閉じる（Zzz の小粒テキストは任意）。操作で目覚める |
| startled | スクロール速度が閾値超 | プルッと震えて向きを戻す |
| dragged | 既存 Draggable | 掴んで投げると elastic で定位置へ帰還（既存実装を相棒に移設） |
| poked | クリック/タップ | スカッシュ＆バウンス + 鳴き（C3） |
| greet | セクション到達 | 小さな反応（下記 章別対応表） |

- reduced-motion: 相棒は静止画で常駐のみ（呼吸・追従・驚きすべて無効）
- 邪魔にならない節度: コンテンツと重なる位置ではフェード退避（footer 手前など）。pointer-events は本体のみ

## C2. 章別演出対応表（意味の再配線）

| 章 | 演出 |
|---|---|
| opening | 現状の落下ムービー＝「相棒がこの世界に降ってくる」。誘導文言を物語文言に（例:「スクロールして あきはを むかえにいく」） |
| hero | 降り立った相棒があなたを紹介。常駐分身はヒーロー通過後に登場 |
| about | ターンテーブル＝観察。キャプションを「AKIHA / 360°」に。相棒はニコニコ見ている |
| activity | **ちび4体（mini_pink/green/blue/yellow）を4つの委員会それぞれの案内役として配置**（既存 peek 素材を row 内に移設。のぞき演出は残してよい） |
| works | 相棒視点の一言（ホバーで小さな吹き出し「これ、つくったんだよ」等、各作品1フレーズ）。家庭教師PFカードは実サイト https://www.nihonhometutor.com/ へのリンク + 実スクリーンショット |
| footer | 相棒がお辞儀。「また遊びに来てね」。奥付に観測日時（C4） |

## C3. 音 = UIの一部（WebAudio 合成、音源ファイルなし）

- 既定 OFF。初回インタラクション後に小さなピル「音を出す？」→ ON でトグル（ヘッダー常設の小アイコン）。設定は localStorage
- 音色（全部 Oscillator/Noise + エンベロープで合成、極小音量）:
  - poked: ぬいぐるみの「ポフッ」+ squeak
  - セクション遷移: 紙をめくる微かなノイズ
  - hover（リンク/ボタン）: ごく微かな鈴
  - opening 完了: やわらかいチャイム1音
- reduced-motion や OFF 時は完全無音。音はBGMではなく操作への応答のみ

## C4. 現実同期（小さく）

- 訪問時刻で紙の色温度をごくわずかに変化（朝: わずかに明るく / 夜: わずかに暖色を落とす。ライト/ダーク両テーマの範囲内で ±数%）
- 奥付に「観測日 YYYY.MM.DD HH:MM」を実時刻で記載

## やらないこと（削る勇気）

- Three.js の3D空間・部屋・歩行 / ゲームパッド・マイク等の特殊入力 / マウスリキッド / AI動的レイアウト / カルーセル追加
- 相棒に関係しない新規ギミック全般

## 実装順

1. **C1 相棒コア**（companion.ts、行動表の appear〜poked まで）+ C2 の文言/配置の再配線
2. C3 音 + C4 現実同期
3. 磨き（greet 詳細、works 吹き出し、実スクショ差し込み）

各波で: taste-skill 規律・reduced-motion・既存回帰（ピン2/works走査/3ガード/自己修復ネット）・本番ビルド検証。
