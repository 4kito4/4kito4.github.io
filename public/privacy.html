プライバシーポリシー

対象アプリケーション: gws-cli／最終更新: 2026年8月28日

gws-cli は、開発者本人が自分の Google アカウントのデータを自分の端末から操作するために作った、 個人用のコマンドラインツールです。一般公開しておらず、開発者以外の利用者を想定していません。 本ポリシーは Google OAuth の同意画面から参照される目的で公開しています。

取得する情報

利用者が OAuth 同意画面で明示的に許可した範囲に限り、Google Workspace API を通じて 利用者自身のアカウントのデータ（Google ドライブのファイル、Gmail のメッセージ、 カレンダーの予定、スプレッドシート、ドキュメント等）にアクセスします。 許可されていない範囲のデータにはアクセスしません。

利用目的

取得したデータは、利用者本人が実行したコマンドを処理するためだけに、 利用者本人の端末上で使用します。それ以外の目的では利用しません。

保存と送信

  • 取得したデータをサーバーに保存しません。gws-cli は利用者の端末上でのみ動作し、開発者が管理するサーバーは存在しません。
  • データの送信先は Google の API エンドポイントに限られます。第三者への提供、販売、共有は一切行いません。
  • アクセストークンおよびリフレッシュトークンは利用者の端末内に暗号化して保存されます（AES-256-GCM、鍵は OS のキーリングに保管）。
  • 広告、解析、機械学習モデルの学習など、いかなる二次利用も行いません。

アクセス権の取り消し

利用者は Google アカウントのアクセス権限ページ からいつでも本アプリの権限を取り消せます。取り消し後、gws-cli はデータにアクセスできなくなります。 端末に保存されたトークンは gws auth logout で削除できます。

Google API サービスのユーザーデータに関するポリシー

gws-cli による Google API から取得した情報の利用および他アプリへの移転は、 Google API サービスのユーザーデータに関するポリシー （限定使用の要件を含む）に準拠します。
